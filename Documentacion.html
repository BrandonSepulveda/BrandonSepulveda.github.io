Documentación de ToolboxBS v4

ToolboxBS es una suite de mantenimiento, reparación y optimización para Windows 10 y 11. Reúne 257 herramientas en una sola aplicación: reparar lo que está roto, recuperar espacio, afinar el rendimiento, revisar la seguridad, diagnosticar la red e instalar software sin dar clic en «Siguiente» cien veces.

Cómo ejecutarlo

Hay dos productos independientes. Usa el que te sirva; no dependen uno del otro.

Aplicación de escritorio

La experiencia completa: consola integrada con la salida en vivo, estado del equipo en tiempo real, reversión de cambios y registro de cada sesión. Abre PowerShell como Administrador y ejecuta: 

irm "https://cutt.ly/ToolboxBS" | iex

Se auto-eleva si hace falta. También puedes descargar el .ps1 firmado desde la sección de releases del repositorio.

Versión web

No instala nada y no necesita permisos: marcas lo que quieres, la página arma un .bat y tú lo ejecutas. Todo se genera en tu navegador, sin enviar datos a ningún servidor, y puedes leer el script completo antes de correrlo.

Abrir la versión web

¿Por qué pide permisos de Administrador? Casi todo lo que hace ToolboxBS —reparar componentes de Windows, tocar servicios, limpiar carpetas del sistema, leer el estado de Defender— requiere privilegios elevados. Sin ellos las herramientas fallarían a medias.

La interfaz

A la izquierda están los módulos; cada herramienta es una tarjeta que se marca con un clic. Abajo a la derecha, el botón Ejecutar corre todo lo seleccionado en orden y te muestra la salida en la consola integrada.

El dashboard

Muestra CPU, memoria, disco y tiempo encendido en vivo, y ocho comprobaciones de salud: activación de Windows, protección en tiempo real de Defender, firewall, antigüedad del último parche, espacio libre, salud SMART de los discos, punto de restauración disponible y si hay un reinicio pendiente.

Perfiles

Si siempre haces lo mismo en los equipos que atiendes, marca las herramientas una vez y guarda un perfil .json. En el siguiente equipo lo cargas y ya tienes la selección lista.

Modo consola

La aplicación de escritorio también funciona sin abrir la ventana, lo que sirve para automatizar mantenimientos o integrarla en tus propios scripts. 

# listar las 257 herramientas con su id y categoria
.\ToolboxBS.ps1 -ListTools

# ejecutar una o varias sin interfaz
.\ToolboxBS.ps1 -RunTool clean-temp,net-info

# volcar el catalogo a JSON (metadata)
.\ToolboxBS.ps1 -ExportCatalog catalogo.json

# volcar el catalogo con el codigo de cada herramienta
.\ToolboxBS.ps1 -ExportCatalog catalogo.full.json -WithCode

# validar el script despues de editarlo
.\ToolboxBS.ps1 -SelfTest

El id es la clave. Cada herramienta de este documento muestra su id (por ejemplo clean-temp). Ese es el mismo identificador que acepta -RunTool.

Dónde quedan los archivos

Todo lo que ToolboxBS genera se guarda en tu carpeta de Documentos, nunca en rutas ocultas.

CarpetaContenido
Documentos\ToolboxBS\logsEl registro completo de cada sesión, con la salida de todas las tareas. Si algo falla, esto es lo que hay que revisar.
Documentos\ToolboxBS\reportesInformes HTML y CSV: reporte del equipo, inventario de software, eventos, drivers, redes WiFi, análisis de espacio.
Documentos\ToolboxBS\backupsRespaldos del registro antes de cada tweak, copia de drivers, claves de BitLocker y de producto, archivo hosts.
Documentos\ToolboxBS\perfilesTus selecciones guardadas en formato JSON.

Riesgos y reversión

Cada herramienta está clasificada. Así se lee la etiqueta:

EtiquetaQué significa
riesgo Hace cambios difíciles de deshacer: borrar Windows.old, eliminar apps preinstaladas, tocar el arranque. La aplicación pide confirmación mostrando la lista exacta antes de ejecutar.
reversible Trae su propia acción de reversión. Desde el clic derecho en la tarjeta, o con el botón «Revertir seleccionados».
ventana Es interactiva o muy larga (SFC, DISM, exámenes completos) y se abre en su propia ventana en vez de la consola integrada.

Antes de tocar el sistema, crea un punto de restauración. Está en Reparación → Crear punto de restauración, y también como casilla «Punto de restauración antes» junto al botón Ejecutar. Todo lo que escribe en el registro hace además un reg export a la carpeta de respaldos.

Solución de problemas

«No se puede cargar el archivo porque la ejecución de scripts está deshabilitada»

Es la directiva de ejecución de PowerShell. Lánzalo así:

powershell -ExecutionPolicy Bypass -File .\ToolboxBS.ps1

Windows Defender bloquea alguna herramienta

Las utilidades de NirSoft (BlueScreenView, BatteryInfoView) suelen marcarse como riesgo porque leen información del sistema. Si las necesitas, agrega una exclusión para %TEMP%\ToolboxBS. Si prefieres no hacerlo, el resto de la herramienta funciona igual: esas solo son un complemento.

La ventana no abre o sale un error de STA

La interfaz usa WPF, que necesita un hilo STA. La aplicación lo detecta y se relanza sola, pero si lo estás llamando desde otro script puedes forzarlo: 

powershell -STA -ExecutionPolicy Bypass -File .\ToolboxBS.ps1

Una tarea falló y no sé por qué

Cada sesión deja su registro completo en Documentos\ToolboxBS\logs, y desde la vista Consola tienes el botón «Abrir registro». Ahí está la salida literal de la tarea, con el error exacto.

¿Qué hace realmente una herramienta antes de ejecutarla?

Clic derecho sobre la tarjeta → Ver el código que ejecuta. Se abre en el Bloc de notas el PowerShell literal que va a correr, sin ejecutarlo. En la versión web, el enlace «ver código» de cada tarjeta hace lo mismo.
